# Constitution

## Project Principles

- AI-driven development follows a disciplined, process-oriented workflow
- All work begins with understanding context before making changes
- Reuse before build; delete before add

## Product Principles

- User needs drive feature priorities
- Simplicity over completeness; YAGNI before over-engineering
- Quality and security are non-negotiable

## Technical Principles

- Spec-Driven Development (SDD) is the default workflow
- Frontend and backend receive equal design attention
- Database and API design must be considered together
- Testing is not optional; coverage matches risk

## UX Principles

- PC and Mobile must both be considered
- Prototype before implement; interactive over static
- Loading, Empty, Error states are first-class requirements

## Security Principles

- Secrets never enter git
- Authentication and authorization are always explicit
- Input validation at every trust boundary
