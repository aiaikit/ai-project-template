# Prototypes

This directory contains interactive prototypes for UI/UX validation.

## Purpose

Prototypes validate:
- Page structure and information hierarchy
- User flows and core interactions
- PC and Mobile layouts
- State changes (Loading, Empty, Error, Success)
- Dialog, Drawer, Form interactions

## Approach

Prototypes should be **interactive**, not static. They are tools for validation, not final deliverables.

## Tools

Prototypes can use any interactive approach:

- HTML / CSS / JavaScript
- Vue / React / Svelte
- Storybook
- Figma (optional)
- Other prototyping tools

**Figma is not required.**

## Workflow

1. Create prototype in this directory
2. Validate with stakeholders
3. Document review notes in the prototype
4. Implement in production code
5. Prototype can be archived or deleted after approval

## Separation

Prototypes are separate from production code. They serve as a reference for implementation but are not maintained as part of the codebase.
